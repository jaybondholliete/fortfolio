Classes

Class Syntax class, extends, constructor

Console output
> const p = new Player("Jay", 100) > p.hp 100 > p.takeDamage(30) > p.hp 70 > p.isAlive() true > const e = new Enemy("Goblin", 50, 10) > e.attack(p) > p.hp 60
class Player {
  constructor(name, hp) {
    this.name = name;
    this.hp = hp;
  }
  takeDamage(n) {
    this.hp = Math.max(0, this.hp - n);
  }
  isAlive() { return this.hp > 0; }
}

class Enemy extends Player {
  constructor(name, hp, damage) {
    super(name, hp);
    this.damage = damage;
  }
  attack(target) { target.takeDamage(this.damage); }
}

OOP Pattern (Metatables)

Class-like Pattern metatable

Lua has no classes — use metatables for OOP.

Lua output
> hero = Player.new("Jay", 100) > hero:takeDamage(20) > print(hero:info()) Jay (HP: 80)
local Player = {}
Player.__index = Player

function Player.new(name, hp)
  local self = setmetatable({}, Player)
  self.name = name
  self.hp = hp
  return self
end

function Player:takeDamage(amount)
  self.hp = math.max(0, self.hp - amount)
end

function Player:info()
  return self.name .. " (HP: " .. self.hp .. ")"
end

-- usage
local hero = Player.new("Jay", 100)
hero:takeDamage(20)
print(hero:info())  -- Jay (HP: 80)
